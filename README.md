# 🤖 Jarvis AI Assistant

A powerful AI-based desktop voice assistant built using Python, Flask, JavaScript, and Speech Recognition that can perform real-time actions on a local computer through voice commands.

## 🚀 Project Overview

Jarvis AI Assistant is a smart local computer automation system that listens to voice commands and performs various desktop operations automatically.  

The assistant uses speech recognition to understand user commands and executes system-level actions like opening applications, controlling volume, searching the web, managing files, and more.

This project was developed completely in Python with a modern web-based interface.

---

# ✨ Features

## 🎤 Voice Recognition
- Real-time speech-to-text conversion
- Recognizes voice commands instantly
- Hands-free computer control

## 💻 Computer Automation
Jarvis can perform multiple local computer actions such as:

- Open Chrome
- Open Excel
- Open YouTube
- Search the Web
- Open Files
- List Files
- Volume Up
- Volume Down
- Mute System
- Unmute System
- Launch Applications
- Execute System Commands

## 🌐 Web-Based Interface
- Modern responsive UI
- Interactive control panel
- Voice command section
- Quick action buttons

## ⚡ Real-Time Command Execution
- Detects command
- Processes text
- Executes action instantly
